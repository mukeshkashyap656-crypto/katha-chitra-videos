# Katha Chitra — Ramayan video template (sab free tools)

Nayi chat mein: "GitHub se Ramayan template uthao" bolna.

- `setup.sh` — HyperFrames, animation library, Hindi fonts aur template ki files ek baar mein lagata hai.
- `lib/` — character kit (Ram, Lakshman, Vishwamitra, Vasishtha, Dasharatha, darbari...), chalte pair (`chars.WALK`), darbar/mahal ke background.
- `draw_assets.py` — UDAHARAN (Bhag 4 test): characters ke saare bhaav/hoth/palak/chalna, dhanush-tarkash, ghana jungle, Tataka ki parchhai, awaaz ke shabdon se hoth, sound effects.
- `build_episode.py` — UDAHARAN: HyperFrames video Bhag 3 ke look mein (border, title box, subtitle box), shot list, karaoke subtitle, chip, subscribe widget, cover.
- `voice_workbench.py` — Madhur awaaz Composio workbench mein banakar Drive par bhejta hai.
- `assets/` — Bhag 3 frame, logo, ungli, kauve, Tataka parchhai, sound effects.
